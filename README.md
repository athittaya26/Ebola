# Ebola
Ebola Disease Analytics Dashboard เป็นระบบวิเคราะห์ข้อมูลโรคอีโบลาด้วย Machine Learning และ Data Visualization

## 📊 Machine Learning Model
Algorithm:
- Random Forest Classifier
Evaluation Metrics:
- Accuracy
- Precision
- Recall
- F1-Score

### Prompt AI
-ขั้นตอนการคลีนข้อมูล Python
-ขั้นตอนการสร้างโมเดลRandom Forest พร้อมโค้ด
-ข้อมูลปัจจัยที่ทำให้เกิดโรคอีโบล่า
-ขั้นตอนการสร้างChart.js
